# FModel Mobile — Android starter

نسخة أولية مفتوحة المصدر لبناء مستكشف ملفات أندرويد مستوحى من FModel. هذا المستودع **ليس بعدُ منفذاً كاملاً لمحرك FModel أو CUE4Parse**.

## الوظائف الموجودة
- اختيار مجلد عبر Android Storage Access Framework دون طلب صلاحيات تخزين عامة.
- عرض الملفات والمجلدات والتنقل داخل المجلد المختار.
- البحث بأسماء العناصر.
- معاينة صور PNG/JPG/JPEG/WebP وملفات نصية شائعة حتى 512 KiB.
- نسخ ملف مختار إلى موقع يختاره المستخدم عبر نافذة إنشاء ملف في أندرويد.
- واجهة Compose داكنة مهيأة للهاتف.

## فتح المشروع
1. ثبّت Android Studio حديثاً مع Android SDK 35 وJDK 17.
2. افتح هذا المجلد في Android Studio.
3. دع Gradle يقوم بالمزامنة.
4. شغّل التطبيق على جهاز أندرويد أو محاكي.

لا يتضمن الأرشيف Gradle Wrapper؛ يمكن لـ Android Studio إعداد/استخدام Gradle المناسب للمشروع.

## البنية المستهدفة
- `app` — واجهة Android/Compose وإدارة ملفات SAF.
- `AssetEngine` (مرحلة لاحقة) — واجهة مستقلة لمحرك قراءة حزم Unreal.
- `Preview` (مرحلة لاحقة) — معاينات خاصة بالقوام والصوت والمجسمات والبيانات الوصفية.
- `Export` — التصدير إلى مجلد يختاره المستخدم مع معالجة الأخطاء والتقدم.

## الخطوة التالية: محرك Unreal Engine
يستخدم FModel مكتبة CUE4Parse لتحليل أرشيفات وحزم Unreal Engine 4/5. ينبغي إضافة طبقة محرك حقيقية بعد اختبار توافق إصدار CUE4Parse واعتمادياته على Android، ثم تنفيذ دعم `.pak` وملفات الفهرسة/الحاويات بحسب اللعبة، وإدارة مفاتيح AES عند الحاجة، ثم فك القوام وتصدير الأصول المدعومة.

**مهم:** وجود ملف `.pak` لا يعني أن محتواه يمكن قراءته من دون ملفات الفهرسة/التبعيات المناسبة، وقد تحتاج بعض الألعاب إلى إصدار محرك أو إعدادات خاصة. هذا النموذج الأولي يتصفح ملفات الجهاز فقط ولا يفك حزم Unreal بعد.

## الترخيص
FModel مرخّص بموجب GPL-3. إذا أُعيد استخدام كود FModel أو توزيعه ضمن عمل مشتق، راجع نص الترخيص ومتطلبات الإسناد وتوفير المصدر. CUE4Parse مشروع منفصل بترخيص Apache-2.0؛ راجع التراخيص الخاصة بكل تبعية قبل التوزيع.


## البناء عبر GitHub Actions
1. ارفع ملفات هذا المشروع إلى مستودع GitHub تملكه، في الفرع `main` أو `master`.
2. افتح تبويب **Actions** في المستودع.
3. اختر سير العمل **Build Android APK** ثم اضغط **Run workflow**، أو ادفع تغييراً إلى الفرع.
4. عند نجاح البناء، افتح نتيجة التشغيل ونزّل `FModel-Mobile-debug-apk` من قسم **Artifacts**.
5. فك ضغط الملف المنزّل؛ ستجد `app-debug.apk` الذي يمكن تثبيته على جهاز أندرويد.

هذا APK تجريبي موقّع بمفتاح debug لأغراض الاختبار، وليس إصداراً إنتاجياً. لم يُختبر البناء على GitHub حتى الآن، ولا يحتوي التطبيق على محرك Unreal/CUE4Parse في هذه المرحلة.
